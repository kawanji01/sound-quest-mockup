# Sound Quest モックアップ v1

子ども向け英語発音学習システムについて、先生と完成像をすり合わせるための動く試作品です。本番のコードではありません。

公開URL：https://kawanji01.github.io/sound-quest-mockup/

## 開き方

```bash
python3 -m http.server 4173 --directory mockup
```

ブラウザで http://localhost:4173 を開きます。ES modules を使っているため、`index.html` を直接開く（`file://`）と動きません。

マイク・カメラ・音声認識は https か localhost でしか動きません。iPad で試すには、https の URL に置く必要があります。

## 画面

| URL | 内容 |
|---|---|
| `#/` | ガイド。先生にお送りする入口。確認事項の一覧と、「候補」機能の表示切り替え |
| `#/kid/login` | こどもの画面。QRコード、または「クラスの番号（4けた）＋出席番号」でログイン |
| `#/teacher` | 先生の画面。クラス一覧、ダッシュボード、児童の詳細、ログイン用QRコード、研究用データ |
| `#/q/4821-5` | QRコードの読み取り先（1年2組5番としてログインする確認画面） |

どの画面でも左下（先生の画面は右下）の「デモ操作」から、画面の切り替え、「候補」機能のオン・オフ、記録の消去ができます。

## 仮のもの（本番で差し替える）

- おてほんの音声：端末の合成音声（`js/audio.js` の `speak`）。12月に先生からいただく音声・動画に差し替える
- ステージの中身：`js/data.js` の `MISSIONS`。Sound Quest の12項目を仮に使用。先生の筋書きに合わせて組み直す
- クラスと児童：`js/data.js` のダミー（さくら小学校 1年2組＝`4821`、5年1組＝`7350`）
- 記録：ブラウザの localStorage にだけ保存する。録音はメモリにだけ置き、ページを閉じると消える。サーバーには何も送らない
- キャラクター「ミミ」：`js/mimi.js` の仮のキャラクター

## ファイル

- `index.html`：入口
- `css/base.css`：共通部品とガイド画面、`css/kid.css`：こどもの画面、`css/teacher.css`：先生の画面
- `js/app.js`：画面の切り替えとデモ操作、`js/kid.js`：こどもの画面、`js/teacher.js`：先生の画面、`js/guide.js`：ガイド
- `js/data.js`：教材とダミーのクラス、`js/state.js`：保存と「候補」機能の一覧、`js/audio.js`：合成音声・録音・音声認識・カメラ
- `js/ui.js`：アイコンや部品、`js/mimi.js`：キャラクター、`js/util.js`・`js/nav.js`：小さな道具
